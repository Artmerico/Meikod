# CineMeikod

Roleta de filmes, batalha e leilão de donates para a live do [MeikodRJ](https://www.twitch.tv/meikodrj).

**Abrir:** https://artmerico.github.io/Meikod/

## Como atualizar
1. Troque o `index.html` pelo novo.
2. Troque o `version.json` (ele leva o número da versão nova).
3. Commit + Push no GitHub Desktop.

A página aberta no PC do streamer confere a versão a cada 3 minutos e recarrega sozinha quando a tela estiver livre.
Os dados (filmes, configurações, token do StreamElements) ficam só no navegador de quem usa — nunca vão pro GitHub.
